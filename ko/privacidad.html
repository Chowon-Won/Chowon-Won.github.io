개인정보 처리방침

최종 업데이트: 2026년 10월 21일

이 방침은 앱 VixArt(도미니카 공화국 ViRav Studio 제작)이 어떤 데이터를 어떤 목적으로 처리하는지, 누구와 공유하는지, 어떻게 삭제할 수 있는지 설명해요. 문의: virav.soporte@gmail.com.

요약
  • 그림은 내 휴대폰에만 저장돼요. 요청하지 않으면 아무것도 업로드되지 않아요.
  • 계정을 만들면 커뮤니티 기능을 위해 이메일과 프로필 정보를 보관해요.
  • 앱에는 Google AdMob 광고가 표시되며, 기기의 광고 ID가 사용될 수 있어요.
  • 데이터를 판매하지 않아요. 계정과 모든 콘텐츠는 앱에서 삭제할 수 있어요.

1. 처리하는 데이터

계정 없이: 가입하지 않고도 그림을 그릴 수 있어요. 그림, 브러시, 설정은 휴대폰 저장공간에 저장되고 어떤 서버로도 전송되지 않아요.

계정이 있을 때 (계정을 만들기로 한 경우에만):

  • 계정 정보: 이메일과 비밀번호(암호화해서 저장하며 저희는 볼 수 없어요), 사용자 이름, 표시 이름, 소개, 프로필 사진.
  • 게시한 콘텐츠: 그림 이미지, 제목, 설명, 태그, 댓글, 좋아요, 팔로우하는 사람, 스토어에 공유한 리소스와 미리보기. 이 모든 것은 VixArt 안에서 공개돼요.
  • 개인 클라우드: 클라우드에 저장하기로 선택한 그림(최대 50 MB). 나만 볼 수 있어요.
  • 포트폴리오: 추가한 작품, 소개, 커미션 참고 가격, X·Instagram·TikTok 사용자 이름. 팀의 승인 후에는 웹 페이지를 포함해 공개됩니다.
  • 아티스트 인증(선택): 법적 이름, 국가, 신청 사유, 작품 이미지, 본인 작품 증거. VixArt 관리자만 볼 수 있습니다.
  • 안전 관련 활동: 내가 한 신고, 차단한 사용자, 즐겨찾기한 글. 모두 비공개예요.
  • 기술 데이터: 보안과 오류 해결을 위해 서버는 IP 주소, 날짜, 요청 유형 같은 데이터를 일정 기간 기록해요.

2. 이용 목적

  • 계정을 만들고 관리하며, 인증 코드나 비밀번호 재설정 코드를 보내기 위해.
  • 다른 사용자에게 내 프로필, 게시물, 리소스를 보여 주고 개인 클라우드를 보관하기 위해.
  • 커뮤니티를 관리하고(신고, 차단) 악용과 스팸을 막기 위해.
  • 앱 운영 비용을 충당하는 광고를 보여 주기 위해.

법적 근거는 계정을 만들고 기능을 사용할 때 하는 사용자의 동의, 그리고 앱을 안전하게 유지하려는 저희의 정당한 이익이에요.

3. 광고 (Google AdMob)

VixArt은 홈 화면에 Google AdMob 배너를 표시해요(편집기 안에는 절대 표시하지 않아요). Google은 광고 표시·측정·부정 방지, 경우에 따라 맞춤 광고를 위해 기기의 광고 ID, IP 주소, 기기의 기술 정보를 수집할 수 있어요. 법으로 요구되는 국가에서는 앱이 Google의 동의 양식을 보여 줘요.

휴대폰의 Google 설정(설정 → Google → 광고)에서 광고 ID를 재설정하거나 삭제하고, 맞춤형이 아닌 광고를 요청할 수 있어요. 자세한 내용: Google 서비스를 사용하는 앱의 데이터를 Google이 사용하는 방법.

4. 공유 대상

저희를 대신해 각자의 서비스를 제공하는 목적으로만 데이터를 처리하는 다음 업체를 이용해요:

  • Supabase: 서버, 데이터베이스, 파일 저장, 계정. 서버는 도미니카 공화국 밖(예: 미국)에 있을 수 있어요.
  • Brevo: 코드가 담긴 이메일 발송.
  • Google AdMob: 광고(3항 참고).

데이터를 판매하거나 대여하지 않아요. 법에 따라 의무가 있을 때만 당국에 제공해요.

5. 보관 기간

계정이 있는 동안 보관해요. 게시물, 댓글, 리소스, 클라우드의 그림을 삭제하면 즉시 서비스에서 제거돼요. 계정을 삭제하면 프로필과 모든 콘텐츠가 삭제돼요. 기술 기록은 며칠 동안만 보관해요.

6. 사용자의 권리

  • 내 데이터 확인 및 수정: 프로필 → 프로필 편집에서.
  • 계정과 모든 콘텐츠 삭제: 앱에서(프로필 → 설정 → 내 계정 삭제) 또는 이메일로 요청. 내 계정 삭제를 참고하세요.
  • 데이터 사본 요청 또는 특정 이용에 대한 이의 제기: virav.soporte@gmail.com으로 연락하세요. 최대 30일 이내에 답변드려요.

이 권리는 도미니카 공화국의 개인정보 보호법(법률 172-13호)과, 해당하는 경우 사용자를 보호하는 다른 법률에 따라 제공돼요.

7. 보안

연결은 암호화돼요(HTTPS). 서버는 작업할 때마다 사용자가 자신에게 해당하는 것만 보고 바꿀 수 있는지 확인해요. 예를 들어 다른 사람은 내 개인 클라우드를 보거나 내 프로필을 수정할 수 없어요. 완벽한 시스템은 없지만, 데이터를 보호하기 위해 노력하고 있어요.

8. 아동

계정을 만들려면 만 13세 이상이어야 해요. VixArt은 만 13세 미만 아동을 대상으로 하지 않아요. 만 13세 미만 아동이 계정을 만들었다고 생각되면 연락해 주세요. 삭제할게요.

9. 변경

이 방침을 바꾸면 위의 날짜를 업데이트하고, 중요한 변경이면 앱에서 알려 드려요.
